프로젝트 소개

국내외 14개 소스에서 데이터를 수집·정규화하고, 캘리브레이션 시세 예측과 규칙 기반 분석으로 일일 시장 리포트를 자동 생성하여 텔레그램으로 발송하는 완전 자동화 파이프라인을 구축합니다.

핵심 요구사항 분석

  • 데이터 수집·스케줄러 — 14개 외부 소스 자동 크롤링, 시간대별 스케줄러, 실패 시 재시도 및 에러 알림, 파싱·정규화, DB Upsert 처리
  • 데이터 처리·분석 엔진 — 복합 계수 적용 캘리브레이션 시세 예측, 재고 일수 및 회전율 분석, 안전마진 고려 복합 매입 추천 점수 산출
  • 규칙 기반 리포트 자동 생성 — 임계치 기반 통계적 시사점 도출, 자체 알고리즘 기반 마켓 플레이북 자동 생성
  • 웹 대시보드·알림 — JWT 로그인/권한 제어, 차량 목록 다중 필터링·정렬, 매입 분석 모달, 일일 리포트 웹 조회 및 PDF 다운로드, 텔레그램 Bot 자동 발송
  • 비기능 요구사항 — Docker Compose 기반 컨테이너 배포, 대용량 데이터 처리 안정성, JWT 인증 및 API 접근 제어

제안 포인트

본 프로젝트의 성패는 ① 14개 이질적 소스의 안정적 수집, ② 신뢰할 수 있는 시세 예측·매입 추천 로직, ③ 딜러가 매일 신뢰하고 여는 리포트·대시보드 세 축에 달려 있습니다. 저희는 다음과 같이 접근합니다.

  • 수집 신뢰성 우선 설계 — 소스별 어댑터 패턴 + 스케줄러(재시도·지수 백오프·실패 알림) + 멱등 Upsert로 "수집 누락 없는 파이프라인"을 1차 마일스톤으로 우선 확보합니다. 15+ 외부 API/크론 자동화 운영 경험을 그대로 적용합니다.
  • 검증 가능한 분석 엔진 — 캘리브레이션 계수·임계치를 설정값으로 외부화하여, 운영 중 튜닝과 백테스트가 가능한 구조로 설계합니다. 시세 예측 결과에 근거(기여 요인)를 함께 노출해 딜러 신뢰를 확보합니다.
  • 리포트 자동 생성 노하우 — 입력 데이터 기반 보고서 자동 작성(AI 투자심사보고서) 플랫폼을 구축한 경험으로, 임계치 기반 시사점·마켓 플레이북을 일일 자동 생성하고 웹 조회·PDF·텔레그램 3채널로 동시 배포합니다.
  • 엔터프라이즈 운영 기준 — JWT·권한 제어, Docker Compose 배포, Nginx 리버스 프록시 등 대규모 B2B 플랫폼 운영 기준을 그대로 적용합니다.
  • 동반 플랫폼 대응 — 함께 공고된 중고차 장기렌탈 B2B 백오피스/에이전트 포털(#156416)까지 통합 대응 가능하여, 데이터·인증·인프라를 일관되게 설계할 수 있습니다.

PRD (Product Requirements Document)

프로젝트 요구사항을 정의하고 기능 범위를 명확히 합니다.

1. 프로젝트 배경 및 목적

중고차 딜러는 매일 시세 파악, 매입 판단, 재고 관리, 수출 동향 파악을 반복합니다. 본 플랫폼은 이 반복 업무를 데이터 기반으로 자동화하여, 딜러가 의사결정에 필요한 정보를 매일 정해진 시간에 자동으로 받아볼 수 있게 합니다. 국내외 14개 소스를 자동 수집하고, 캘리브레이션 시세 예측·매입 추천·재고 회전율 분석을 통해 일일 시장 리포트를 자동 생성하여 웹·PDF·텔레그램으로 배포하는 완전 자동화 파이프라인 구축이 목표입니다.
